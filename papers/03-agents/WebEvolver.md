# WebEvolver: Enhancing Web Agent Self-Improvement with Coevolving World Model

## 基本信息

- **作者**: Tianqing Fang 等
- **机构**: 腾讯 AI Lab
- **发表会议**: arXiv 预印本（2025）
- **论文链接**: https://arxiv.org/abs/2504.21024
- **代码链接**: https://github.com/Tencent/SelfEvolvingAgent
- **关键词**: World Model, Web Agent, Co-Evolution, Self-Instruction, Look-Ahead Simulation
- **摘要**: 智能体自我改进——即智能体的骨干大语言模型（LLM）基于自身策略自主采样的轨迹进行训练——已成为提升性能的有前景方法。近期进展，特别是在 Web 环境中，面临一个关键限制：其性能在自主学习循环中会达到**停滞点（stagnation point）**，阻碍进一步改进。我们认为这源于 Web 环境的有限探索和对 LLM 中预训练 Web 知识利用不足。为提升自我改进的性能，我们提出一个新框架，引入一个**协同进化的 World Model（世界模型）LLM**。该世界模型基于 Web 环境中的当前观察和动作预测下一个观察。利用 LLM 对丰富 Web 内容的预训练知识，世界模型承担双重角色：(1) 作为**虚拟 Web 服务器**生成自指令训练数据以持续精炼智能体策略；(2) 作为推理时的**想象引擎（imagination engine）**，启用前瞻模拟以指导智能体的动作选择。在真实 Web 环境（Mind2Web-Live、WebVoyager 和 GAIA-web）的实验中，相比现有自进化智能体实现了 **10% 的性能提升**，且未使用任何来自更强闭源模型的蒸馏。我们的工作确立了将世界模型整合进自主智能体框架以释放持续适应性的必要性。
- **TLDR 太长不想读**: WebEvolver 解决 Web Agent 自进化的**停滞问题**。核心是引入一个**协同进化的世界模型 LLM**，它扮演两个角色：(1) 虚拟 Web 服务器——生成自指令训练数据；(2) 想象引擎——推理时前瞻模拟，指导动作选择。世界模型利用 LLM 预训练的 Web 知识。在真实 Web 环境提升 10%，且不蒸馏闭源大模型。核心：**用世界模型突破自进化的探索瓶颈**。

## Q1: 这篇论文试图解决什么问题？（按照引言逻辑）

**背景**：Agent 自我改进（用自身策略采样的轨迹训练骨干 LLM）是有前景的方法。

**痛点**：Web 环境中，自改进会在**停滞点（stagnation point）**停滞——原因：(1) Web 环境探索有限；(2) LLM 预训练 Web 知识利用不足。

**缺口**：如何突破 Web Agent 自进化的停滞？

**本文贡献**：引入协同进化的 World Model LLM，双重角色（虚拟服务器 + 想象引擎），提升 10%。

## Q2: 有哪些相关研究？

- **Web Agent**：WebArena、Mind2Web、WebVoyager；
- **自进化 Agent**：用自身轨迹训练；
- **世界模型**：Dreamer 式环境预测；
- **自指令**：Self-Instruct 生成训练数据；
- **前瞻搜索**：MCTS、look-ahead。

WebEvolver 的独特之处：**世界模型作为虚拟环境 + 想象引擎**，协同进化。

## Q3: 论文如何解决这个问题？（核心框架解释）

**核心机制：协同进化的 World Model LLM**

世界模型基于**当前观察 + 动作**预测**下一个观察**（Web 环境的状态转移）。

**双重角色**：

1. **虚拟 Web 服务器（Virtual Web Server）**：
   - 生成**自指令训练数据**以持续精炼智能体策略；
   - **为什么**：真实 Web 环境探索受限（不能随便点、有速率限制）；虚拟服务器可无限生成交互数据，扩大探索。

2. **想象引擎（Imagination Engine）**：
   - 推理时进行**前瞻模拟（look-ahead simulation）**指导动作选择；
   - **为什么**：在执行真实动作前先"想象"结果，避免错误操作，提升决策质量。

**为什么能突破停滞**：
- 停滞源于探索不足 → 虚拟服务器扩展探索；
- 停滞源于知识利用不足 → 世界模型利用 LLM 的预训练 Web 知识。

**协同进化**：世界模型与智能体一起进化——智能体变强，世界模型预测更准；世界模型更准，智能体学得更好。

**关键优势**：**无需蒸馏闭源大模型**——纯自进化。

- **环境**：真实 Web 环境（Mind2Web-Live、WebVoyager、GAIA-web）；

## Q5: 论文做了哪些实验？

- **环境**：Mind2Web-Live、WebVoyager、GAIA-web；
- **结果**：相比现有自进化 Agent **+10%**；
- **条件**：不使用更强闭源模型的蒸馏。

## Q6: 这篇论文的创新点和可以借鉴的地方

- **创新点**：世界模型双重角色（虚拟环境 + 想象引擎）；协同进化突破停滞。
- **可借鉴**：
  1. **世界模型可扩展受限环境的探索**；
  2. **前瞻模拟**提升决策质量；
  3. 利用 LLM 预训练知识（如 Web 知识）作为世界模型的基础。

## Q7: 这篇论文有哪些不足

- 世界模型预测误差会累积，影响训练质量；
- Web 环境高度动态，虚拟服务器可能偏离真实分布；
- 世界模型的训练/维护成本；
- 10% 提升在部分基准上可能不显著。

## Q8: 提炼论文的一般技术和逻辑范式

**范式**：`World-Model-Augmented Self-Evolution`

```
真实环境(受限) → World Model(虚拟服务器+想象引擎)
   → 扩展探索 + 前瞻模拟 → 智能体+世界模型协同进化 → 突破停滞
```

核心：**用世界模型突破自进化的探索与知识瓶颈**，适用于任何环境交互受限的场景。

- **上位类**：世界模型增强的自进化
- **下位类**：环境预测、前瞻搜索、协同进化

### 研究设计
1. **预测误差控制**：研究世界模型误差累积的抑制方法；
2. **分布漂移**：研究虚拟环境与真实环境的分布对齐；
3. **跨环境迁移**：世界模型能否跨网站/跨领域迁移。
