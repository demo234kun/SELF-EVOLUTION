# SEEA-R1: Tree-Structured Reinforcement Fine-Tuning for Self-Evolving Embodied Agents

## 基本信息

- **作者**: Wanxin Tian 等
- **机构**: 北京人形机器人创新中心、北京大学
- **发表会议**: arXiv 预印本（2025）
- **论文链接**: https://arxiv.org/abs/2506.21669
- **代码链接**: 未提供
- **关键词**: Reinforcement Fine-Tuning (RFT), Embodied Agent, Tree-GRPO, MCTS, Multi-modal Reward Model
- **摘要**: 自进化——智能体自主改进其推理和行为的能力——对于长视野真实世界任务的具身领域至关重要。尽管当前强化微调（RFT）的进展在增强 LLM 推理方面表现强劲，但其在多模态交互下实现自进化具身智能的潜力仍大多未被探索。具体而言，RFT 在具身设置中面临两个根本障碍：(i) 多步推理任务中缺乏可访问的中间奖励，限制了有效学习信号；(ii) 依赖手工设计的奖励函数，限制了向新任务和环境的泛化。为应对这些挑战，我们提出 **Self-Evolving Embodied Agents-R1（SEEA-R1）**，首个专为具身智能体实现自进化能力而设计的 RFT 框架。具体而言，为将稀疏延迟奖励转化为更稠密的中间信号以改进多步推理，我们提出 **Tree-based group relative policy optimization（Tree-GRPO）**，将蒙特卡洛树搜索（MCTS）集成到 GRPO 中。为跨任务和场景泛化奖励估计、支持自主适应和奖励驱动的自进化，我们进一步引入**多模态生成奖励模型（MGRM）**。为全面评估 SEEA-R1 的有效性，我们在 **ALFWorld** 基准上评估，以 **85.07%（文本）和 46.27%（多模态）** 的分数超越最先进方法，优于包括 GPT-4o 在内的先前模型。SEEA-R1 在**无 ground truth 奖励**时也取得 **80.3%（文本）和 44.03%（多模态）**，超越所有开源基线，凸显其作为自进化具身智能体的可扩展性。
- **TLDR 太长不想读**: SEEA-R1 是**首个为具身 Agent 设计的 RFT 框架**。解决两个障碍：(1) 多步推理缺中间奖励；(2) 手工奖励难泛化。方案：**Tree-GRPO**——把 MCTS 集成进 GRPO，将稀疏延迟奖励转为稠密中间信号；**MGRM**（多模态生成奖励模型）泛化奖励估计。ALFWorld 上文本 85.07%、多模态 46.27%，超越 GPT-4o；无真值奖励时 80.3%/44.03% 仍超所有开源基线。核心：**用树搜索 + 生成式奖励模型实现具身自进化**。

## Q1: 这篇论文试图解决什么问题？（按照引言逻辑）

**背景**：自进化对具身领域（长视野真实任务）至关重要；RFT 在 LLM 推理上有效，但具身多模态场景未探索。

**痛点**：RFT 在具身设置面临两个障碍：
1. **缺乏可访问的中间奖励**——多步推理任务只有稀疏延迟奖励，学习信号弱；
2. **依赖手工奖励函数**——难以泛化到新任务/环境。

**缺口**：如何设计具身场景的 RFT，实现自进化？

**本文贡献**：SEEA-R1，Tree-GRPO（MCTS+GRPO）+ MGRM（多模态生成奖励模型）。

## Q2: 有哪些相关研究？

- **强化微调（RFT）**：用 RL 微调推理能力；
- **GRPO**：群体相对策略优化；
- **MCTS**：蒙特卡洛树搜索；
- **具身 Agent**：ALFWorld、具身问答；
- **生成式奖励模型**：用模型生成奖励。

## Q3: 论文如何解决这个问题？（核心框架解释）

**核心机制：两个关键组件**

1. **Tree-GRPO（Tree-based Group Relative Policy Optimization）**：
   - **是什么**：把 **MCTS（蒙特卡洛树搜索）**集成进 **GRPO**；
   - **为什么用 MCTS**：多步推理中，最终奖励稀疏且延迟；MCTS 通过树展开探索多条推理路径，提供**中间状态的价值估计**；
   - **解决障碍 1**：将**稀疏延迟奖励转化为稠密的中间信号**；
   - **GRPO 的作用**：群体相对策略优化——通过组内相对比较估计优势，无需 critic 模型，训练稳定。

2. **MGRM（Multi-modal Generative Reward Model）**：
   - **是什么**：多模态生成式奖励模型；
   - **为什么用**：手工奖励函数难泛化；生成式奖励模型可**跨任务和场景泛化奖励估计**；
   - **解决障碍 2**：支持**自主适应和奖励驱动的自进化**——无需真值奖励。

**为什么能自进化**：MGRM 提供泛化奖励 → 智能体在无真值奖励时也能学习 → 持续自进化。

**实验结果**：
- **ALFWorld**：文本 **85.07%** / 多模态 **46.27%**，超越 GPT-4o；
- **无真值奖励**：文本 **80.3%** / 多模态 **44.03%**，超越所有开源基线。

- **ALFWorld**：文本 85.07% / 多模态 46.27%（超 GPT-4o）；

## Q6: 这篇论文的创新点和可以借鉴的地方

- **创新点**：Tree-GRPO（MCTS 稠密化奖励）；MGRM（泛化奖励估计）；首个具身 RFT 自进化框架。
- **可借鉴**：
  1. **MCTS 将稀疏奖励稠密化**——解决多步推理的关键；
  2. **生成式奖励模型**替代手工奖励，提升泛化；
  3. 无真值奖励下的自进化可行。

## Q7: 这篇论文有哪些不足

- 多模态性能（46.27%）显著低于文本（85.07%）——视觉推理仍难；
- MGRM 的奖励可能被钻空子；
- ALFWorld 是仿真环境，真实具身未验证；
- 计算成本高（MCTS + RL）。

## Q8: 提炼论文的一般技术和逻辑范式

**范式**：`Tree-Search Dense Reward + Generative Reward Model`

```
多步任务 → Tree-GRPO(MCTS稠密化奖励) + MGRM(泛化奖励)
   → 自进化具身Agent
```

核心：**用树搜索把稀疏奖励变稠密，用生成式模型把手工奖励变泛化**。
