# Do Self-Evolving Agents Forget? Capability Degradation and Preservation in Lifelong LLM Agent Adaptation

## 基本信息

- **作者**: Ye Yu 等
- **机构**: 伊利诺伊大学厄巴纳-香槟分校
- **发表会议**: arXiv 预印本（2026）
- **论文链接**: https://arxiv.org/abs/2605.09315
- **代码链接**: 未提供
- **关键词**: Capability Erosion, Lifelong Learning, Continual Adaptation, Catastrophic Forgetting, CPE
- **摘要**: 近期 LLM 智能体的进展使系统能够自主精炼工作流、积累可复用技能、自训练其底层模型并维护持久记忆。然而，我们表明这种自进化往往**非单调**：适应新任务分布会渐进地**退化先前获得的能力**，在所有主要进化通道中一致出现。我们将这一现象识别为**自进化下的能力侵蚀（capability erosion under self-evolution）**，并表明它在工作流、技能、模型和记忆进化中一致出现。为缓解这一问题，我们提出 **Capability-Preserving Evolution（CPE）**，一个通用稳定化原则，约束持续适应中的破坏性能力漂移。在所有四个进化维度上，CPE 一致地提升了保留能力的稳定性，同时保持适应性能。例如，在工作流进化中，CPE 在 GPT-5.1 优化下将保留的简单任务性能从 41.8% 提升到 52.8%，同时实现更强的复杂任务适应。我们的发现表明，稳定的长期自进化智能体不仅需要获取新能力，还需要在持续适应中显式地保留先前学到的能力。
- **TLDR 太长不想读**: 这篇论文揭示了一个关键问题：**自进化会导致遗忘**。适应新任务会渐进退化旧能力，在工作流/技能/模型/记忆四个通道都出现。提出 **CPE（Capability-Preserving Evolution）** 稳定化原则，约束破坏性漂移。工作流进化中保留能力从 41.8%→52.8%。核心洞察：**稳定的自进化 = 获取新能力 + 显式保留旧能力**，二者缺一不可。这是对"自进化总是好的"的重要反驳。

## Q1: 这篇论文试图解决什么问题？（按照引言逻辑）

**背景**：LLM Agent 能自主精炼工作流、积累技能、自训练、维护记忆。

**痛点**：这种自进化**非单调**——适应新任务会**渐进退化旧能力**（能力侵蚀），在四个进化通道一致出现。

**缺口**：如何让自进化**不遗忘**？

**本文贡献**：
1. 识别并命名"自进化下的能力侵蚀"；
2. 提出 CPE 稳定化原则；
3. 在四维度验证 CPE 有效。

## Q2: 有哪些相关研究？

- **灾难性遗忘**：持续学习经典问题；
- **持续学习**：EWC、SI 等防遗忘方法；
- **自进化 Agent**：EvolveR、ACE（本文指出其遗忘风险）；
- **能力保持**：稳定-可塑性困境。

## Q3: 论文如何解决这个问题？（核心框架解释）

**核心发现：能力侵蚀（Capability Erosion）**

在**四个进化通道**中，适应新任务会退化旧能力：

1. **工作流进化（Workflow）**：优化工作流适应新任务 → 旧任务的简单工作流失效；
2. **技能进化（Skill）**：积累新技能 → 旧技能被覆盖/干扰；
3. **模型进化（Model）**：自训练适应新分布 → 旧分布性能下降（经典灾难性遗忘）；
4. **记忆进化（Memory）**：新记忆累积 → 旧记忆被挤出或干扰。

**核心方案：CPE（Capability-Preserving Evolution）**

一个**通用稳定化原则**：约束持续适应中的**破坏性能力漂移（destructive capability drift）**。

**为什么有效**：CPE 在进化的同时施加约束，防止新适应"覆盖"旧能力。它不阻止适应（保持可塑性），而是约束破坏性漂移（保持稳定性）——解决稳定-可塑性困境。

**实验结果**：
- 工作流进化中，GPT-5.1 优化下，保留的简单任务性能从 **41.8% → 52.8%**；
- 同时实现**更强的复杂任务适应**（不是用适应换保留）。

## Q6: 这篇论文的创新点和可以借鉴的地方

- **创新点**：识别并命名"自进化下的能力侵蚀"；CPE 通用原则。
- **可借鉴**：
  1. **自进化必须监控旧能力保持**，不能只看新任务性能；
  2. 稳定-可塑性权衡是自进化的核心挑战；
  3. 保留能力与适应能力可兼得（CPE 证明）。

## Q7: 这篇论文有哪些不足

- CPE 的具体机制未详述，可复现性受限；
- 四通道的度量标准可能不一致；
- 长期（数百轮）进化的累积侵蚀未研究；
- 计算成本（保留旧能力的开销）未评估。

## Q8: 提炼论文的一般技术和逻辑范式

**范式**：`Stability-Aware Self-Evolution`

```
适应新任务 → 可能侵蚀旧能力(四通道) → CPE约束破坏性漂移
   → 兼顾适应与保留
```

核心：**自进化的评价必须是双目标**——新任务适应 + 旧能力保留。
