# SAGE: Multi-Agent Self-Evolution for LLM Reasoning

## 基本信息

- **作者**: Yu-Li Peng 等
- **机构**: 深圳大学、人工智能与数字经济广东省实验室（深圳）、卡尔顿大学
- **发表会议**: arXiv 预印本（2026）
- **论文链接**: https://arxiv.org/abs/2603.15255
- **代码链接**: 未提供
- **关键词**: Multi-Agent, Self-Evolution, Curriculum Drift, Planning, Quality Control, Verifiable Rewards
- **摘要**: 带可验证奖励的强化学习（RLVR）提升了 LLM 的推理能力，但许多方法仍依赖大量人工标注数据集。虽然自对弈减少了这种依赖，但它往往缺乏显式规划和强质量控制，限制了长视野多步推理中的稳定性。我们提出 **SAGE（Self-evolving Agents for Generalized reasoning Evolution）**，一个闭环框架，其中四个智能体——**Challenger（挑战者）、Planner（规划者）、Solver（求解者）和 Critic（批评者）**——从共享的 LLM 骨干共同进化，仅使用一个小型种子集。Challenger 持续生成越来越难的任务；Planner 将每个任务转换为结构化的多步计划；Solver 遵循计划产生答案，其正确性由外部验证器确定。Critic 对生成的问题和计划进行评分和过滤，以防止**课程漂移（curriculum drift）**并维持训练信号质量，从而实现稳定的自我训练。在数学和代码生成基准上，SAGE 在不同模型规模上带来一致的提升，将 Qwen-2.5-7B 模型在 LiveCodeBench 上提升 8.9%，在 OlympiadBench 上提升 10.7%。
- **TLDR 太长不想读**: SAGE 用**四角色闭环**（Challenger 出题、Planner 计划、Solver 解题、Critic 评分过滤）解决自对弈的稳定性问题。关键创新是 **Critic 防止课程漂移**——过滤掉质量差的问题和计划，保持训练信号可靠。加上显式的 Planner 角色处理多步推理。Qwen-2.5-7B 在 LiveCodeBench +8.9%、OlympiadBench +10.7%。

## Q1: 这篇论文试图解决什么问题？（按照引言逻辑）

**背景**：RLVR 提升推理，但依赖大量人工标注；自对弈减少依赖。

**痛点**：自对弈**缺乏显式规划和强质量控制**，导致长视野多步推理中不稳定（课程漂移——生成的题目越来越偏，训练信号质量下降）。

**缺口**：如何在自对弈中引入规划与质量控制，保证长视野推理的稳定进化？

**本文贡献**：提出 SAGE 四角色闭环框架，用 Critic 过滤防止课程漂移，用 Planner 处理多步推理。

## Q2: 有哪些相关研究？

- **RLVR**：带可验证奖励的 RL；
- **自对弈**：R-Zero、MAE；
- **多智能体协作**：角色分工；
- **课程学习**：难度调度；
- **过程监督**：Planner 类工作。

SAGE 的独特组合：**四角色 + Critic 质量过滤 + 显式规划**。

## Q3: 论文如何解决这个问题？（核心框架解释）

**核心机制：四角色闭环共进化**（共享 LLM 骨干，仅用小种子集）

1. **Challenger（挑战者）**：持续生成越来越难的任务；
2. **Planner（规划者）**：把每个任务转化为**结构化多步计划**；
3. **Solver（求解者）**：遵循计划产生答案，正确性由**外部验证器**判定；
4. **Critic（批评者）**：对生成的问题和计划**评分并过滤**。

**为什么需要 Critic**：这是本文的关键创新。纯自对弈中，Challenger 可能生成**无意义或过于偏斜**的题目（课程漂移），Planner 可能生成低质计划。Critic 通过评分过滤，**维持训练信号质量**，保证稳定自训练。

**为什么需要 Planner**：长视野多步推理需要显式规划。Planner 把任务分解为步骤，使 Solver 的推理过程可控、可验证。

**为什么用外部验证器**：答案正确性由外部验证器（而非 LLM 评判）确定，属于验证层级中的**执行/形式验证**，信号强。

## Q4: 论文使用的训练数据/结构细节/来源等详细信息（可复现目标）

- **数据**：仅使用**小型种子集**，其余自生成；
- **骨干**：共享 LLM 骨干，四角色实例化；
- **验证**：外部验证器判定答案正确性；
- **基准**：数学 + 代码生成（LiveCodeBench、OlympiadBench）。

## Q5: 论文做了哪些实验？

- **模型规模**：不同规模模型上均有一致提升；
- **结果**：Qwen-2.5-7B 在 **LiveCodeBench +8.9%**、**OlympiadBench +10.7%**；
- **意义**：证明四角色 + Critic 过滤能稳定提升长视野推理。

## Q6: 这篇论文的创新点和可以借鉴的地方

- **创新点**：Critic 过滤机制防止课程漂移；Planner 显式规划处理多步推理；四角色闭环。
- **可借鉴**：
  1. **质量控制是自对弈稳定的关键**——Critic 过滤可推广到其他自进化系统；
  2. 显式规划角色提升长视野任务表现；
  3. 小种子集 + 自生成数据的高效组合。

## Q7: 这篇论文有哪些不足

- 四角色的 RL 训练复杂，计算开销大；
- Critic 本身可能被钻空子（评判偏差）；
- 外部验证器限制了适用领域（需可验证答案）；
- 未讨论长期训练中的能力遗忘问题。

## Q8: 提炼论文的一般技术和逻辑范式

**范式**：`Quality-Controlled Multi-Agent Curriculum`

```
种子集 → Challenger出题 → Critic过滤(防漂移) → Planner计划 → Solver解题
   → 外部验证器判定 → 四角色共进化
```

核心：**在自对弈回路中加入"质量门"（Critic）**，把不稳定的自博弈变为稳定的课程进化。

## Q9: 针对这篇文章，思考有哪些值得做的研究话题

### 研究主题

- **上位类**：稳定的多智能体自进化
- **下位类**：课程漂移检测、质量过滤、规划增强
- **同位类**：R-Zero、MAE、课程学习

### 数据类型
- 自生成问题-计划-答案三元组、验证器标签

### 研究设计
1. **课程漂移度量**：设计量化课程漂移的指标并对比过滤策略；
2. **Critic 替代方案**：研究用规则/统计方法替代 LLM Critic，降低成本；
3. **规划粒度研究**：研究计划粒度对长视野推理的影响。
