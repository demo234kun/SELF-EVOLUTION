# Evolutionary System Prompt Learning for Reinforcement Learning in LLMs (E-SPL)

## 基本信息

- **作者**: Lunjun Zhang 等
- **机构**: 多伦多大学、西北大学、Bridgewater AIA Labs
- **发表会议**: arXiv 预印本（2026）
- **论文链接**: https://arxiv.org/abs/2602.14697
- **代码链接**: https://github.com/LunjunZhang/E-SPL
- **关键词**: System Prompt, Evolutionary RL, Context-Weight Synergy, Mutation, Crossover
- **摘要**: 构建能够从经验中自主自我改进的智能体系统是 AI 的长期目标。当今大语言模型（LLM）主要通过两种机制自我改进：用于上下文更新的自我反思，以及用于权重更新的强化学习（RL）。在本工作中，我们提出 **Evolutionary System Prompt Learning（E-SPL）**，一种**联合改进模型上下文和模型权重**的方法。在每次 RL 迭代中，E-SPL 在多个系统提示下**并行采样轨迹**，然后联合地对 LLM 权重应用 RL 更新、对系统提示应用进化更新。系统提示通过**突变（mutation）和交叉（crossover）**两个遗传算子进化，由 LLM 自我反思驱动；选择基于跨 RL 迭代更新的相对性能评级。E-SPL 鼓励**提示中编码的陈述性知识与权重中编码的程序性知识之间的自然分工**，从而在推理和智能体任务上提升性能。例如，在易到难（AIME → BeyondAIME）的泛化设置中，E-SPL 将 RL 成功率从 38.8% 提升到 45.1%，同时超越反思式提示进化（40.0%）。总体而言，我们的结果表明 RL 与系统提示进化深度协同，二者结合在样本效率和泛化上带来一致增益。
- **TLDR 太长不想读**: E-SPL 让**系统提示和模型权重协同进化**。每次 RL 迭代：在多个系统提示下并行采样轨迹，然后同时做 RL 更新（改权重）和进化更新（改提示）。提示通过**突变+交叉**进化，由 LLM 自反思驱动，选择基于相对性能评级。关键洞察：**提示编码陈述性知识（知道什么），权重编码程序性知识（知道怎么做）**，二者分工。AIME→BeyondAIME 成功率 38.8%→45.1%。

## Q1: 这篇论文试图解决什么问题？（按照引言逻辑）

**背景**：LLM 自我改进有两条路径——自我反思（改上下文）和 RL（改权重）。

**痛点**：二者通常**分开使用**，未联合优化。

**缺口**：能否**同时进化上下文和权重**，让它们协同？

**本文贡献**：提出 E-SPL，联合 RL 权重更新 + 进化提示更新。

## Q2: 有哪些相关研究？

- **自我反思**：Reflexion、提示进化（如反思式提示进化）；
- **RL 训练**：GRPO、PPO；
- **进化算法**：突变、交叉、选择；
- **提示优化**：EvoPrompt；
- **陈述性 vs 程序性知识**：认知科学概念。

## Q3: 论文如何解决这个问题？（核心框架解释）

**核心机制：RL 与提示进化的联合**

**每次 RL 迭代**：
1. 在**多个系统提示**下**并行采样轨迹**；
2. **联合更新**：
   - 对 LLM **权重**应用 **RL 更新**；
   - 对**系统提示**应用**进化更新**。

**提示进化（遗传算子）**：
- **突变（Mutation）**：由 LLM 自我反思驱动的提示改写；
- **交叉（Crossover）**：组合不同提示的部分；
- **选择（Selection）**：基于**跨 RL 迭代更新的相对性能评级**。

**为什么有效——知识分工假说**：
- **提示编码陈述性知识（declarative）**："知道什么"（规则、策略、约束）；
- **权重编码程序性知识（procedural）**："知道怎么做"（推理能力、技能）；
- 二者分工，避免重复，提升效率与泛化。

**实验结果**：
- AIME → BeyondAIME（易到难泛化）：RL 成功率 **38.8% → 45.1%**；
- 超越反思式提示进化（40.0%）。

## Q4: 论文使用的训练数据/结构细节/来源等详细信息（可复现目标）

- **任务**：推理 + 智能体任务；
- **泛化设置**：AIME → BeyondAIME；
- **机制**：多提示并行采样 + RL 权重更新 + 进化提示更新；
- **代码**：https://github.com/LunjunZhang/E-SPL

## Q5: 论文做了哪些实验？

- **泛化设置**：AIME → BeyondAIME；
- **结果**：成功率 38.8% → **45.1%**；
- **对比**：超越反思式提示进化（40.0%）；
- **结论**：RL + 提示进化深度协同，提升样本效率与泛化。

## Q6: 这篇论文的创新点和可以借鉴的地方

- **创新点**：联合进化权重与提示；遗传算子（突变/交叉）+ 相对性能选择；知识分工假说。
- **可借鉴**：
  1. **权重与上下文协同**——不要只优化其一；
  2. 用进化算法优化提示，与 RL 并行；
  3. 陈述性/程序性知识分工是理解提示-权重关系的有力视角。

## Q7: 这篇论文有哪些不足

- 多提示并行采样增加计算成本；
- 遗传算子的设计需调参；
- 知识分工是假说，未严格验证；
- 主要在推理任务，其他领域泛化未知。

## Q8: 提炼论文的一般技术和逻辑范式

**范式**：`Co-Evolution of Context and Weights`

```
多提示并行采样 → RL更新权重 + 进化更新提示(突变/交叉/选择)
   → 知识分工(陈述性@提示, 程序性@权重) → 协同提升
```

核心：**上下文与权重不是替代关系，而是互补分工**。
