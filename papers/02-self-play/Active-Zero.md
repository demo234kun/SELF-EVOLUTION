# Active-Zero: Self-Evolving Vision-Language Models through Active Environment Exploration

## 基本信息

- **作者**: Jinghan He 等
- **机构**: 未公开（arXiv 预印本）
- **发表会议**: arXiv 预印本（2026）
- **论文链接**: https://arxiv.org/abs/2602.11241
- **代码链接**: 未提供
- **关键词**: Vision-Language, Active Exploration, Self-Play, Auto-Curriculum, Capability Frontier
- **摘要**: 自对弈使大语言模型能够通过自生成的挑战实现自主改进。然而，现有的视觉语言模型（VLM）自对弈方法依赖与静态图像集合的被动交互，导致对初始数据集的强依赖和低效学习。没有能力主动寻找适合其演变能力的视觉数据，智能体将计算浪费在过于简单或超出当前技能水平的样本上。为应对这些限制，我们提出 **Active-Zero**，一个从被动交互转向**主动探索视觉环境**的框架。Active-Zero 采用三个共进化智能体：一个 **Searcher**，基于模型的能力前沿从开放世界仓库检索图像；一个 **Questioner**，合成校准的推理任务；以及一个通过准确性奖励精炼的 **Solver**。这一闭环实现了自脚手架自动课程，模型自主构建其学习轨迹。在 Qwen2.5-VL-7B-Instruct 上，跨 12 个基准，Active-Zero 在推理任务上实现 53.97 平均准确率（5.7% 提升），在通用理解上实现 59.77（3.9% 提升），持续超越现有自对弈基线。
- **TLDR 太长不想读**: Active-Zero 把 VLM 自对弈从"被动看静态图片"升级为"**主动探索视觉环境**"。三个共进化角色：Searcher 根据模型能力前沿从开放世界检索图片，Questioner 合成校准任务，Solver 解题。关键洞察：静态图像集会浪费算力在太简单或太难的样本上，主动检索才能构建有效的自脚手架课程。Qwen2.5-VL-7B 推理 +5.7%。

## Q1: 这篇论文试图解决什么问题？（按照引言逻辑）

**背景**：自对弈让 LLM 自主改进；VLM 自对弈依赖静态图像集。

**痛点**：静态图像集导致**强数据依赖**和**低效学习**——模型无法主动寻找适合自身能力的视觉数据，算力浪费在过易/过难样本上。

**缺口**：如何让 VLM 自对弈**主动探索**视觉环境，构建有效课程？

**本文贡献**：提出 Active-Zero，三角色主动探索框架，实现自脚手架自动课程。

## Q2: 有哪些相关研究？

- **VLM 自对弈**：静态图像集上的问答博弈；
- **主动学习**：选择信息量大的样本；
- **自动课程**：难度自适应；
- **R-Zero / MAE**：LLM 自对弈（被动，无主动检索）；
- **开放世界数据检索**：从大型图像库检索。

Active-Zero 的独特之处：**主动检索**替代静态数据集。

## Q3: 论文如何解决这个问题？（核心框架解释）

**核心机制：三角色主动探索**

1. **Searcher（搜索者）**：
   - 基于模型的**能力前沿（capability frontier）**从开放世界仓库检索图像；
   - **为什么**：确保检索到的图像难度匹配当前能力——不太易也不太难。

2. **Questioner（提问者）**：
   - 合成**校准的推理任务**（针对检索到的图像）；
   - **为什么**：任务难度需与图像和模型能力对齐。

3. **Solver（求解者）**：
   - 通过**准确性奖励**精炼；
   - **目标**：解决 Questioner 提出的任务。

**闭环：自脚手架自动课程（Self-Scaffolding Auto-Curriculum）**
- 模型**自主构建学习轨迹**——Searcher 找到合适数据，Questioner 出合适题，Solver 学习，能力提升后 Searcher 检索更难数据……形成螺旋。

**关键洞察**：数据选择（Searcher）与任务生成（Questioner）解耦，且都以"能力前沿"为目标，实现真正的主动学习。

## Q4: 论文使用的训练数据/结构细节/来源等详细信息（可复现目标）

- **数据**：从**开放世界图像仓库**主动检索（非固定数据集）；
- **角色**：Searcher + Questioner + Solver 共进化；
- **基座**：Qwen2.5-VL-7B-Instruct；
- **评测**：12 个基准（推理 + 通用理解）。

## Q5: 论文做了哪些实验？

- **基座**：Qwen2.5-VL-7B-Instruct；
- **推理任务**：53.97 平均准确率（**+5.7%**）；
- **通用理解**：59.77（**+3.9%**）；
- **对比**：持续超越现有自对弈基线。

## Q6: 这篇论文的创新点和可以借鉴的地方

- **创新点**：主动视觉环境探索；Searcher 基于能力前沿检索；自脚手架自动课程。
- **可借鉴**：
  1. **主动数据选择**是提升自对弈效率的关键；
  2. "能力前沿"作为检索/出题的统一目标；
  3. 数据与任务解耦设计提升灵活性。

## Q7: 这篇论文有哪些不足

- 依赖开放世界图像仓库的质量与覆盖；
- 检索模块增加系统复杂度与成本；
- 7B 模型验证，更大规模未知；
- 能力前沿的估计方法未详述，可能不稳健。

## Q8: 提炼论文的一般技术和逻辑范式

**范式**：`Active Exploration Self-Play`

```
能力前沿 → Searcher检索匹配数据 → Questioner合成任务 → Solver解题
   → 能力提升 → 前沿前移 → 循环
```

关键：把"被动接收数据"变为"主动寻求数据"，是自对弈效率的重要升级。

## Q9: 针对这篇文章，思考有哪些值得做的研究话题

### 研究主题

- **上位类**：主动自进化（Active Self-Evolution）
- **下位类**：数据检索策略、能力前沿估计、任务校准
- **同位类**：主动学习、课程学习、VLM 自对弈

### 数据类型
- 开放世界图像、自生成多模态 QA

### 研究设计
1. **前沿估计**：研究更稳健的能力前沿估计方法（如不确定性度量）；
2. **检索效率**：优化 Searcher 的检索成本-收益；
3. **多模态扩展**：把主动探索扩展到视频/音频等更多模态。
