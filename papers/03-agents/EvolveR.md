# EvolveR: Self-Evolving LLM Agents through an Experience-Driven Lifecycle

## 基本信息

- **作者**: Rong Wu 等
- **机构**: 浙江大学、上海人工智能实验室、华东师范大学、复旦大学、中南大学、上海创智学院、上海交通大学、中国科学技术大学
- **发表会议**: arXiv 预印本（2025）
- **论文链接**: https://arxiv.org/abs/2510.16079
- **代码链接**: https://github.com/Edaizi/EvolveR
- **关键词**: Experience Lifecycle, Self-Distillation, Policy Reinforcement, Tool Use, Multi-Hop QA
- **摘要**: 当前的大语言模型（LLM）智能体在工具使用方面表现强劲，但缺乏系统性地从自身经验中学习的关键能力。现有框架主要关注缓解外部知识差距，却未能解决一个更根本的局限：**无法迭代地精炼问题解决策略**。在本工作中，我们提出 **EvolveR**，一个旨在使智能体通过完整的、闭环的经验生命周期实现自我改进的框架。该生命周期包含两个关键阶段：(1) **离线自蒸馏（Offline Self-Distillation）**，智能体的交互轨迹被合成为结构化的、可复用的抽象策略原则库；(2) **在线交互（Online Interaction）**，智能体与任务交互并主动检索蒸馏出的原则来指导其决策，累积多样化的行为轨迹。这一循环采用**策略强化机制（policy reinforcement mechanism）**，基于智能体的表现迭代更新它。我们在复杂的多跳问答基准上展示了 EvolveR 的有效性，它超越了强大的智能体基线。我们的工作为不仅从外部数据、也从自身行动后果中学习的智能体提供了全面的蓝图。
- **TLDR 太长不想读**: EvolveR 提出"**经验驱动的完整生命周期**"。两个阶段：(1) 离线自蒸馏——把交互轨迹提炼成可复用的抽象策略原则库；(2) 在线交互——主动检索这些原则指导决策，同时积累新轨迹。用策略强化机制迭代更新。在多跳问答上超越强基线。核心：Agent 不仅要学外部数据，更要学**自己行动的后果**。

## Q1: 这篇论文试图解决什么问题？（按照引言逻辑）

**背景**：LLM Agent 工具使用能力强。

**痛点**：缺乏**系统性从自身经验学习**的能力；现有框架只缓解"外部知识差距"，未解决更根本的"**无法迭代精炼问题解决策略**"。

**缺口**：如何让 Agent 从自己的行为后果中学习，形成闭环？

**本文贡献**：提出 EvolveR，完整闭环经验生命周期（离线自蒸馏 + 在线交互 + 策略强化）。

## Q2: 有哪些相关研究？

- **经验检索**：Reflexion、ExpeL；
- **技能库**：Voyager；
- **自蒸馏**：从轨迹提取知识；
- **策略优化**：RL、策略强化；
- **自进化 Agent**：ACE、AgentEvolver。

EvolveR 的独特之处：**完整闭环**——离线提炼 + 在线检索 + 策略强化，三者贯通。

## Q3: 论文如何解决这个问题？（核心框架解释）

**核心机制：经验驱动的闭环生命周期**

**阶段一：离线自蒸馏（Offline Self-Distillation）**
- 把智能体的交互轨迹**合成为结构化的、可复用的抽象策略原则库**；
- **为什么**：原始轨迹冗长、噪声多；提炼为"抽象原则"后可复用、可检索；
- 相当于把"具体经验"升华为"通用策略"。

**阶段二：在线交互（Online Interaction）**
- 智能体与任务交互，**主动检索蒸馏出的原则**指导决策；
- 同时**累积多样化的行为轨迹**（为下一轮离线蒸馏提供素材）；
- **为什么**：检索原则让当前任务做得更好，累积轨迹让系统持续学习。

**策略强化机制（Policy Reinforcement）**
- 基于智能体表现**迭代更新**；
- **为什么**：形成正向循环——表现好 → 强化有效策略 → 更好。

**闭环**：
```
交互 → 轨迹 → 离线蒸馏(提炼原则) → 在线检索(指导决策) → 新轨迹 → ...
         ↑______________________________________________|
                    策略强化
```

## Q4: 论文使用的训练数据/结构细节/来源等详细信息（可复现目标）

- **数据**：智能体交互轨迹（自生成）；
- **原则库**：抽象策略原则（从轨迹蒸馏）；
- **评测**：多跳问答基准；
- **代码**：https://github.com/Edaizi/EvolveR

## Q5: 论文做了哪些实验？

- **基准**：复杂多跳问答（multi-hop QA）；
- **结果**：**超越强智能体基线**；
- **意义**：证明完整经验生命周期能有效提升 Agent 表现。

## Q6: 这篇论文的创新点和可以借鉴的地方

- **创新点**：完整闭环经验生命周期；离线自蒸馏提炼抽象原则；在线检索 + 策略强化。
- **可借鉴**：
  1. **经验要"升华"为原则**，而非简单存储轨迹；
  2. 离线提炼与在线检索结合，兼顾质量与实时性；
  3. 策略强化形成持续改进的正循环。

## Q7: 这篇论文有哪些不足

- 原则库持续增长可能引入检索噪声（与 Self-Consolidation 呼应）；
- 策略强化机制的具体形式未详述；
- 主要在多跳 QA 验证，其他领域泛化未知；
- 未讨论长期进化的稳定性与遗忘问题。

## Q8: 提炼论文的一般技术和逻辑范式

**范式**：`Experience Lifecycle (Distill → Retrieve → Reinforce)`

```
交互轨迹 → 离线自蒸馏(抽象原则库) → 在线检索(指导) → 新轨迹
   → 策略强化 → 循环
```

核心：把"经验"转化为"可复用策略"，实现从行动后果中学习。

## Q9: 针对这篇文章，思考有哪些值得做的研究话题

### 研究主题

- **上位类**：经验驱动 Agent 自进化
- **下位类**：自蒸馏、原则检索、策略强化
- **同位类**：Reflexion、技能库、RAG

### 数据类型
- 交互轨迹、抽象原则、任务表现

### 研究设计
1. **原则库管理**：研究原则的去重、抽象层次与检索效率；
2. **强化机制设计**：对比不同策略强化方法的收敛性；
3. **跨领域迁移**：研究原则能否跨任务域迁移复用。
