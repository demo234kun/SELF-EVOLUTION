# Teaching LLMs to Self-Evolve: Cultivating Core Meta-Skills with Reinforcement Learning (MetaEvolve)

## 基本信息

- **作者**: Shujin Wu 等
- **机构**: 伊利诺伊大学厄巴纳-香槟分校
- **发表会议**: arXiv 预印本（2026）
- **论文链接**: https://arxiv.org/abs/2607.21971
- **代码链接**: 未提供
- **关键词**: Meta-Skills, Evolution-Aware RL, Self-Reflection, Cross-Domain Transfer, Verifiable Rewards
- **摘要**: 通过环境反馈进行迭代自进化的测试时扩展（如 AlphaEvolve 所展示的）显示出显著的性能提升。我们假设此类进化框架的成功依赖于**元技能（meta-skills）**，例如带环境反馈的自我反思，这些元技能使有效的多轮精炼成为可能，却被传统后训练在很大程度上忽视。为弥合这一差距，我们提出 **MetaEvolve**，一个旨在通过**数据合成管道、进化感知强化学习（RL）和推理时进化搜索**来培养这些元技能的框架。具体而言，我们将 MetaEvolve 植根于编码，其中程序执行提供了超越二值正确性的自然、连续奖励信号。基于这些信号，我们**合成进化轨迹作为训练数据**，每条包含当前程序、其适应度分数（结合正确性和效率）以及先前尝试的历史，并通过**基于可验证奖励的 RL**（奖励来自测试用例执行）训练模型。通过在大型代码数据上训练，我们旨在激发可广泛迁移到此类丰富训练信号稀缺的开放式问题的**通用、领域无关的元技能**。在七个编码基准上，MetaEvolve 在分布内任务上超越最强基线 **10.01% 绝对值**，在分布外任务上超越 **24.12%**。在完全在训练域之外的开放式算法优化问题上，它进一步实现了 **46.9% 的相对提升**。这些结果表明，显式培养自进化元技能为通往更有能力和自主自进化的 AI 提供了一条原则性路径。
- **TLDR 太长不想读**: MetaEvolve 的核心假说：**自进化框架的成功依赖于"元技能"**（如带环境反馈的自我反思），而传统后训练忽视了这些。方案：用编码任务（执行提供连续奖励）合成**进化轨迹**（当前程序+适应度+历史），用可验证奖励 RL 训练模型。结果：7 个编码基准分布内 +10.01%、分布外 +24.12%，开放式算法优化相对 +46.9%。核心：**显式培养元技能，使其能跨域迁移**。

## Q1: 这篇论文试图解决什么问题？（按照引言逻辑）

**背景**：通过环境反馈的迭代自进化（如 AlphaEvolve）性能显著。

**痛点**：这类框架的成功**依赖于元技能**（如带反馈的自我反思），但**传统后训练忽视这些元技能**。

**缺口**：能否**显式培养**这些元技能，并使其**跨域迁移**到训练信号稀缺的开放问题？

**本文贡献**：MetaEvolve，通过数据合成 + 进化感知 RL + 推理时搜索培养元技能。

## Q2: 有哪些相关研究？

- **AlphaEvolve**：进化搜索框架；
- **自我反思**：Reflexion；
- **RLVR**：可验证奖励的 RL；
- **元学习**：学习如何学习；
- **测试时扩展**：推理时搜索。

## Q3: 论文如何解决这个问题？（核心框架解释）

**核心机制：培养元技能的三步**

**关键假说**：自进化框架的成功依赖**元技能**（如"带环境反馈的自我反思"），这些是可迁移的通用能力。

1. **数据合成管道（Data Synthesis Pipeline）**：
   - **植根于编码**——程序执行提供**自然、连续的奖励信号**（超越二值正确性）；
   - **合成进化轨迹（Evolution Trajectories）**作为训练数据，每条包含：
     - 当前程序；
     - **适应度分数（fitness score）**：结合正确性 + 效率；
     - **先前尝试的历史**；
   - **为什么**：模拟真实的进化过程，让模型学习"如何从历史中改进"。

2. **进化感知 RL（Evolution-Aware RL）**：
   - 用**基于可验证奖励的 RL**（奖励来自测试用例执行）训练；
   - **为什么**：可验证奖励可靠（验证层级高端），训练信号强。

3. **推理时进化搜索（Inference-Time Evolutionary Search）**：
   - 训练后，模型在推理时执行进化搜索；
   - **为什么**：元技能在推理时发挥，实现测试时扩展。

**跨域迁移目标**：在代码上训练，但目标是激发**领域无关的元技能**，迁移到训练信号稀缺的开放问题。

## Q5: 论文做了哪些实验？

- **7 个编码基准**：
  - 分布内：**+10.01% 绝对值**；
  - 分布外：**+24.12%**；
- **开放式算法优化**（训练域之外）：**+46.9% 相对提升**；
- **意义**：证明元技能可跨域迁移。

## Q6: 这篇论文的创新点和可以借鉴的地方

- **创新点**：把"自进化能力"归因于可培养的**元技能**；进化轨迹合成；可验证奖励 RL。
- **可借鉴**：
  1. **显式培养元技能**比让模型自己摸索更高效；
  2. **进化轨迹**（程序+适应度+历史）是有价值的训练数据形式；
  3. 在强验证域（代码）训练，迁移到弱验证域。

## Q7: 这篇论文有哪些不足

- 元技能的定义与度量偏定性；
- 迁移到开放域的实际效果（+46.9% 是算法优化，仍偏结构化）；
- 合成轨迹的多样性依赖代码域；
- 训练成本高。

## Q8: 提炼论文的一般技术和逻辑范式

**范式**：`Meta-Skill Cultivation via Evolution Trajectories`

```
代码任务(强验证) → 合成进化轨迹(程序+适应度+历史)
   → 进化感知RL训练 → 元技能(自我反思) → 跨域迁移
```

核心：**把"自进化"本身当作一种可训练的能力**，在强验证域习得后迁移。
