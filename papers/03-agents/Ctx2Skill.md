# From Context to Skills: Can Language Models Learn from Context Skillfully? (Ctx2Skill)

## 基本信息

- **作者**: Shuzheng Si 等
- **机构**: 伊利诺伊大学厄巴纳-香槟分校、DeepLang AI、复旦大学、香港中文大学、清华大学
- **发表会议**: arXiv 预印本（2026）
- **论文链接**: https://arxiv.org/abs/2604.27660
- **代码链接**: 未提供
- **关键词**: Skill Discovery, Context Learning, Multi-Agent Self-Play, Cross-time Replay, Adversarial Collapse
- **摘要**: 许多真实世界任务要求语言模型（LM）在超出其参数知识的复杂上下文上进行推理。这需要**上下文学习（context learning）**，即 LM 直接从给定上下文中学习相关知识。一个直观的解决方案是**推理时技能增强（inference-time skill augmentation）**：将上下文中的规则和程序提取为自然语言技能。然而，为上下文学习场景构建此类技能面临两个挑战：为长而技术密集的上下文进行人工技能标注的成本过高，以及缺乏用于自动技能构建的外部反馈。在本文中，我们提出 **Ctx2Skill**，一个自进化框架，在无人监督或外部反馈的情况下自主发现、精炼和选择上下文特定技能。其核心是一个**多智能体自对弈循环**：一个 **Challenger** 生成探测任务和评分标准，一个 **Reasoner** 在演进的技能集指导下尝试解决它们，一个中立的 **Judge** 提供二值反馈。关键在于，Challenger 和 Reasoner 都通过累积的技能进化：专门的 **Proposer 和 Generator 智能体**分析失败案例并将其合成为针对双方的定向技能更新，实现自动技能发现与精炼。为防止由越来越极端的任务生成和过度专门化的技能积累导致的**对抗坍塌（adversarial collapse）**，我们进一步引入 **Cross-time Replay 机制**，识别在代表性案例上达到最佳平衡的技能集，确保稳健且可泛化的技能进化。产生的技能可插入任何语言模型以获得更好的上下文学习能力。在 CL-bench 的四个上下文学习任务上评估，Ctx2Skill 持续提升各骨干模型的解决率。
- **TLDR 太长不想读**: Ctx2Skill 解决"**如何从上下文中自动提炼技能**"。挑战：人工标注技能太贵，自动构建又缺反馈。方案：多智能体自对弈——Challenger 出探测题+评分标准，Reasoner 用演进技能解题，Judge 给二值反馈。Proposer/Generator 分析失败案例合成技能更新。关键创新是 **Cross-time Replay** 防止**对抗坍塌**（任务越来越极端、技能过度专门化）。技能可插入任意 LM。

## Q1: 这篇论文试图解决什么问题？（按照引言逻辑）

**背景**：真实任务需要 LM 在超出参数知识的复杂上下文上推理（上下文学习）。

**痛点**：推理时技能增强是直观方案，但面临两个挑战：
1. **人工技能标注成本过高**（长而技术密集的上下文）；
2. **缺乏自动技能构建的外部反馈**。

**缺口**：如何**无监督、无外部反馈**地自动发现、精炼、选择上下文特定技能？

**本文贡献**：Ctx2Skill 自进化框架 + Cross-time Replay 防对抗坍塌。

## Q2: 有哪些相关研究？

- **上下文学习（In-Context Learning）**：从上下文学习；
- **技能提取**：把规则/程序转为自然语言；
- **多智能体自对弈**：MAE、R-Zero；
- **对抗坍塌**：GAN 式训练中的经典问题；
- **CL-bench**：上下文学习基准。

## Q3: 论文如何解决这个问题？（核心框架解释）

**核心机制：多智能体自对弈的技能进化**

**三个核心角色**：
1. **Challenger（挑战者）**：生成**探测任务（probing tasks）和评分标准（rubrics）**；
2. **Reasoner（推理者）**：在**演进的技能集**指导下尝试解决；
3. **Judge（评判者，中立）**：提供**二值反馈**。

**技能进化机制**：
- **Proposer 和 Generator 智能体**分析**失败案例**，合成为**针对双方的定向技能更新**；
- Challenger 和 Reasoner **都**通过累积技能进化；
- 实现自动技能发现与精炼，无需外部反馈。

**关键创新：Cross-time Replay（跨时间回放）**
- **问题**：对抗自对弈会导致**对抗坍塌**——任务越来越极端，技能过度专门化（只对极端任务有效，失去泛化）；
- **方案**：识别在**代表性案例上达到最佳平衡的技能集**；
- **作用**：确保稳健且可泛化的技能进化。

**为什么技能可迁移**：产生的技能是自然语言的，可**插入任何语言模型**提升上下文学习能力。

- **结果**：**持续提升各骨干模型的解决率**；

## Q6: 这篇论文的创新点和可以借鉴的地方

- **创新点**：无外部反馈的技能自进化；Cross-time Replay 防对抗坍塌；技能可插拔。
- **可借鉴**：
  1. **从失败案例合成技能更新**（成功+失败并重）；
  2. **对抗坍塌**是自对弈的常见陷阱，需回放机制；
  3. 自然语言技能具有跨模型可迁移性。

## Q7: 这篇论文有哪些不足

- 多智能体（5 角色）系统复杂，成本高；
- 评分标准（rubrics）的质量依赖 Challenger 能力；
- CL-bench 任务范围有限；
- 技能集持续增长的管理未详述。

## Q8: 提炼论文的一般技术和逻辑范式

**范式**：`Self-Play Skill Discovery with Replay`

```
上下文 → Challenger出题+评分标准 → Reasoner用技能解题 → Judge二值反馈
   → Proposer/Generator分析失败合成技能 → Cross-time Replay防坍塌
   → 可插拔技能集
```

核心：**把"技能"作为可进化的自然语言制品**，通过自对弈自动发现。
