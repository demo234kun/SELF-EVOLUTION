# Self-Play Only Evolves When Self-Synthetic Pipeline Ensures Learnable Information Gain

## 基本信息

- **作者**: Wei Liu 等
- **机构**: 伦敦国王学院、艾伦·图灵研究所
- **发表会议**: arXiv 预印本（2026）
- **论文链接**: https://arxiv.org/abs/2603.02218
- **代码链接**: 未提供
- **关键词**: Learnable Information Gain, Sustainable Evolution, Self-Play Theory, Proposer-Solver-Verifier, Asymmetric Co-Evolution
- **摘要**: 大语言模型（LLM）使得构建通过自进化循环改进的系统成为可能，但许多现有方案更适合被理解为自对弈，且往往迅速停滞。一个核心失败模式是：循环合成了更多数据，却没有为下一轮迭代增加可学习信息。通过在一个自对弈编码任务上的实验，我们揭示：**可持续的自进化需要一个自合成数据管道，其可学习信息跨迭代递增**。我们识别出自进化 LLM 扮演的**三元角色**：**Proposer（提议者）**，生成任务；**Solver（求解者）**，尝试解答；**Verifier（验证者）**，提供训练信号。我们从这一三元角色视角识别出三个共同针对"可学习信息增益"的系统设计：**非对称共进化（Asymmetric Co-Evolution）** 闭合跨角色的弱-强-弱循环；**容量增长（Capacity Growth）** 扩展参数和推理时预算以匹配上升的可学习信息；**主动信息寻求（Proactive Information Seeking）** 引入外部上下文和新任务源以防止饱和。这些模块共同提供了一条可测量的、系统级的路径，从脆弱的自对弈动力学走向可持续的自进化。
- **TLDR 太长不想读**: 这篇论文给出了"自对弈为什么会停滞"的**理论诊断**：因为合成了更多数据但没增加**可学习信息（learnable information）**。可持续自进化要求信息增益跨迭代递增。它提出三个系统设计：非对称共进化（弱-强-弱循环）、容量增长（预算匹配信息）、主动信息寻求（引入外部上下文）。这是一篇偏理论/诊断的论文，为整个自对弈领域提供了"可持续性判据"。

## Q1: 这篇论文试图解决什么问题？（按照引言逻辑）

**背景**：LLM 可通过自进化循环改进。

**痛点**：许多"自进化"方案实质是自对弈，且**迅速停滞**——核心失败模式是**合成了更多数据但未增加可学习信息**。

**缺口**：可持续自进化的**必要条件**是什么？如何设计满足该条件的系统？

**本文贡献**：
1. 揭示可持续自进化需要**可学习信息增益跨迭代递增**；
2. 识别三元角色（Proposer/Solver/Verifier）；
3. 提出三个系统设计（非对称共进化/容量增长/主动信息寻求）。

## Q2: 有哪些相关研究？

- **自对弈 RL**：R-Zero、MAE（本文诊断其停滞原因）；
- **信息论 / 课程学习**：信息增益、可学习性；
- **自合成数据**：合成数据退化（模型坍塌）；
- **开放-endedness**：持续新颖性；
- **容量扩展**：模型/算力扩展律。

## Q3: 论文如何解决这个问题？（核心框架解释）

**核心理论：可学习信息增益（Learnable Information Gain）**

**诊断**：自对弈停滞的根因是——**合成了更多数据，但新数据未提供"可学习"的新信息**（如题目重复、答案已在能力范围内）。可持续性要求：**每一轮迭代的可学习信息 > 上一轮**（或至少非递减）。

**三元角色框架**：
1. **Proposer**：生成任务；
2. **Solver**：尝试解答；
3. **Verifier**：提供训练信号。

**三个系统设计（共同保证信息增益递增）**：

1. **非对称共进化（Asymmetric Co-Evolution）**：
   - 闭合跨角色的"弱-强-弱"循环——角色能力不均衡，弱者被强者拉动；
   - **为什么**：对称共进化容易同质化（都停在同水平），非对称产生持续张力。

2. **容量增长（Capacity Growth）**：
   - 扩展参数和推理时预算以匹配上升的可学习信息；
   - **为什么**：若容量固定，信息增益很快饱和（学不动了）；容量必须同步增长。

3. **主动信息寻求（Proactive Information Seeking）**：
   - 引入**外部上下文和新任务源**，防止饱和；
   - **为什么**：纯自生成数据的信息上限受限于模型自身知识；必须从外部获取新信息。

**实验**：在自对弈编码任务上验证——这三个设计共同实现可持续自进化。

- **任务**：自对弈编码任务；
- **角色**：Proposer/Solver/Verifier 三元组；
- **外部源**：主动信息寻求引入外部上下文/任务；

## Q5: 论文做了哪些实验？

- **实验设置**：自对弈编码任务；
- **关键发现**：无信息增益的循环会停滞；引入三个设计后可持续进化；
- **度量**：可学习信息增益（跨迭代）。

## Q6: 这篇论文的创新点和可以借鉴的地方

- **创新点**：提出"可学习信息增益递增"作为可持续自进化的判据；三元角色 + 三设计的系统框架。
- **可借鉴**：
  1. 设计自进化系统时，**监控每轮信息增益**，而非只看数据量；
  2. 非对称共进化 > 对称共进化；
  3. 容量与信息必须同步增长；
  4. 引入外部信息源防止饱和。

## Q7: 这篇论文有哪些不足

- "可学习信息"的度量在文中未给出普适定义（依赖任务）；
- 三个设计的具体实现细节有限；
- 实验仅限编码任务，跨领域泛化未验证；
- 理论分析偏定性，缺乏收敛性证明。

## Q8: 提炼论文的一般技术和逻辑范式

**范式**：`Information-Gain-Driven Sustainable Evolution`

```
自合成数据 → 度量可学习信息增益 → 若增益不增则停滞
   → 三设计(非对称共进化 + 容量增长 + 主动信息寻求) → 持续进化
```

核心判据：**自进化的可持续性 = 可学习信息增益是否跨迭代递增**。

## Q9: 针对这篇文章，思考有哪些值得做的研究话题

### 研究主题

- **上位类**：可持续自进化的条件与设计
- **下位类**：信息增益度量、非对称共进化、容量调度、外部信息引入
- **同位类**：课程学习、开放-endedness、模型坍塌

### 数据类型
- 自合成任务数据、信息增益度量、外部任务源

### 研究设计
1. **信息增益度量**：设计跨任务通用的"可学习信息"度量；
2. **非对称比例优化**：研究角色能力差距多大时共进化最有效；
3. **容量-信息协同调度**：研究算力预算与信息增益的最优匹配策略。
