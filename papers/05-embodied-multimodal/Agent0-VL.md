# Agent0-VL: Exploring Self-Evolving Agent for Tool-Integrated Vision-Language Reasoning

## 基本信息

- **作者**: Jiaqi Liu 等
- **机构**: 未公开（arXiv 预印本，与 Agent0 同团队 aiming-lab）
- **发表会议**: arXiv 预印本（2025）
- **论文链接**: https://arxiv.org/abs/2511.19900
- **代码链接**: https://github.com/aiming-lab/Agent0
- **关键词**: Vision-Language, Tool-Integrated, Self-Rewarding, Tool-Grounded Verification, Self-Evolving Reasoning Cycle
- **摘要**: 视觉语言智能体在多模态推理任务中取得了显著进展；然而，它们的学习仍受限于人工标注监督的局限。近期的自奖励方法试图通过让模型充当自己的批评者或奖励提供者来克服这一限制。然而，纯文本的自我评估难以验证复杂的视觉推理步骤，且常遭受**评估幻觉（evaluation hallucinations）**。为应对这些挑战，受工具集成推理近期进展的启发，我们提出 **Agent0-VL**，一个通过工具集成推理实现持续改进的自进化视觉语言智能体。Agent0-VL 将工具使用不仅纳入推理，还纳入**自我评估和自我修复**，使模型能够通过**基于证据的分析（evidence-grounded analysis）**内省、验证和精炼其推理。它在单一 LVLM 中统一两个协同角色：一个执行多轮工具集成推理的 **Solver**，和一个通过工具锚定批评生成结构化反馈和细粒度自奖励的 **Verifier**。这两个角色通过**自进化推理循环（Self-Evolving Reasoning Cycle）**交互，其中基于工具的验证和强化学习共同对齐推理和评估分布以实现稳定自改进。通过这一**零外部奖励**的进化，Agent0-VL 在无任何人工标注或外部奖励模型的情况下对齐其推理和验证行为，实现持续自改进。在几何问题求解和视觉科学分析上的实验表明，Agent0-VL 相比基座模型实现了 **12.5% 的提升**。
- **TLDR 太长不想读**: Agent0-VL 解决"**纯文本自评估难以验证视觉推理**"的问题（评估幻觉）。核心：把**工具使用**纳入推理、自我评估和自我修复，实现**基于证据的分析**。在单一 LVLM 中统一两个角色：Solver（多轮工具推理）和 Verifier（工具锚定的结构化反馈+细粒度自奖励）。通过**自进化推理循环**，工具验证和 RL 共同对齐推理与评估分布。零外部奖励下，几何问题 +12.5%。核心：**工具锚定验证**替代不可靠的纯文本自评估。

## Q1: 这篇论文试图解决什么问题？（按照引言逻辑）

**背景**：视觉语言 Agent 在多模态推理上有进展，但学习受限于人工标注。

**痛点**：自奖励方法（模型自评）有根本问题——**纯文本自评估难以验证复杂视觉推理步骤**，常产生**评估幻觉**。

**缺口**：如何实现**可靠**的视觉推理自评估与自进化？

**本文贡献**：Agent0-VL，把工具使用纳入推理+评估+修复，实现证据锚定的自进化。

## Q2: 有哪些相关研究？

- **视觉语言 Agent**：多模态推理；
- **自奖励**：模型自评（本文指出其评估幻觉问题）；
- **工具集成推理**：用工具增强推理（如计算器、视觉工具）；
- **Agent0**：同团队的前作（文本自进化）；
- **自我精炼**：迭代改进。

## Q3: 论文如何解决这个问题？（核心框架解释）

**核心机制：工具锚定的双角色自进化**

**关键创新：把工具使用扩展到评估和修复**

传统自奖励只用文本自评 → 视觉推理验证困难。Agent0-VL 让工具不仅用于推理，还用于**自我评估和自我修复**，实现**基于证据的分析（evidence-grounded analysis）**。

**两个协同角色（单一 LVLM 内）**：
1. **Solver（求解者）**：
   - 执行**多轮工具集成推理**；
   - 用工具（计算、视觉分析等）辅助推理。

2. **Verifier（验证者）**：
   - 通过**工具锚定的批评（tool-grounded critique）**生成**结构化反馈**和**细粒度自奖励**；
   - **为什么工具锚定**：避免纯文本自评的幻觉——用工具验证提供客观证据。

**自进化推理循环（Self-Evolving Reasoning Cycle）**：
- Solver 和 Verifier 交互；
- **基于工具的验证 + 强化学习**共同**对齐推理和评估分布**；
- 实现稳定自改进。

**关键优势：零外部奖励**
- 无人工标注；
- 无外部奖励模型；
- 完全靠工具锚定的自我验证。

**结果**：几何问题求解 + 视觉科学分析，相比基座模型 **+12.5%**。

## Q6: 这篇论文的创新点和可以借鉴的地方

- **创新点**：工具锚定验证替代纯文本自评；工具用于评估+修复；零外部奖励自进化。
- **可借鉴**：
  1. **工具锚定**是解决评估幻觉的有效手段；
  2. 把工具从"推理辅助"扩展到"评估辅助"；
  3. Solver-Verifier 双角色在单一模型内统一。

## Q7: 这篇论文有哪些不足

- 工具集范围有限，复杂视觉推理仍难；
- 工具调用增加成本/延迟；
- 12.5% 提升的绝对性能未详述；
- 依赖工具可用性，无工具时退化。

## Q8: 提炼论文的一般技术和逻辑范式

**范式**：`Tool-Grounded Self-Evaluation`

```
Solver(工具集成推理) ↔ Verifier(工具锚定批评+自奖励)
   → 自进化推理循环(工具验证+RL) → 零外部奖励自进化
```

核心：**用工具锚定验证替代不可靠的纯文本自评**，解决评估幻觉。
